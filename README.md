🧠 Face Recognition Model

A real-time Face Recognition System built using Python, OpenCV, and the face_recognition library.
This project can detect and recognize multiple faces through your webcam in real time with high accuracy.

🧩 Features

✅ Real-time face detection and recognition
✅ Cross-Platform: Works on Windows, macOS, and Linux
✅ Advanced Accuracy: Uses `face_distance` algorithms to perfectly distinguish between similar faces
✅ Multi-Person Support: Easily organize training data using folders
✅ Incremental Training: Train new faces individually without having to retrain the entire dataset
✅ Modular code: Separate scripts for encoding & live recognition

⚙️ Project Structure

face_recognition_app/
│
├── encode_faces.py              # Encodes known faces and saves encodings
├── face_recognition_live.py     # Detects and recognizes faces live via webcam
├── encodings.pkl                # Serialized face encodings (generated by script)
├── images/                      # Organized image dataset
│   ├── Arun/                    # Folder containing images of Arun
│   │   └── Arun.jpg             
│   └── Ansul/                   # Folder containing images of Ansul
│       └── Ansul.jpg            
└── README.md                    # Project documentation


🧰 Requirements

Install dependencies using pip:
pip install opencv-python face_recognition dlib numpy

⚠️ Note for Linux/Kali users:
dlib requires cmake and build-essential:
sudo apt update
sudo apt install cmake build-essential python3-pip

⚠️ Note for Windows users:
Installing `dlib` requires installing Visual Studio C++ Build Tools and CMake.


🧠 How It Works

1. `encode_faces.py` → Scans the `images/` directory. Each sub-directory is treated as a person's name. It generates encodings and saves them into `encodings.pkl`.
2. `face_recognition_live.py` → Opens the webcam, reads live frames, compares detected faces with stored encodings using "best match distance", and displays the name if matched.

▶️ How to Run

Step 1 — Organize Your Images
Create a folder for each person inside the `images/` directory and place their photos inside it:
- `images/Arun/`
- `images/Ansul/`
- `images/John/`

Step 2 — Encode Known Faces
To train the model on all folders from scratch:
python encode_faces.py

To train the model on a specific person (without overwriting existing encodings):
python encode_faces.py Ansul


Step 3 — Start Live Recognition
python face_recognition_live.py

Step 4 — Test
Look into the camera — it should recognize your face and display your folder's name (e.g., *Arun*). To quit, press the `q` key on your keyboard.

🧪 Example Output

When a face is detected, the OpenCV window will draw a green bounding box around the face with the recognized name tag floating above it. If multiple people are in the frame, it will identify all of them simultaneously!
