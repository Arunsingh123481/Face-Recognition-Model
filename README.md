🧠 Face Recognition Model (Kali Linux)

A real-time Face Recognition System built and tested on Kali Linux using Python, OpenCV, and the face_recognition library.
This project can detect and recognize faces through your webcam in real time.

🧩 Features

✅ Real-time face detection and recognition

✅ Works on any Linux (tested on Kali Linux)

✅ Uses face_recognition and dlib for accurate encoding

✅ Easy to train with new faces

✅ Modular code (separate scripts for encoding & live recognition)

⚙️ Project Structure

face_recognition_app/
│
├── encode_faces.py              # Encodes known faces and saves encodings
├── face_recognition_live.py     # Detects and recognizes faces live via webcam
├── encodings.pkl                # Serialized face encodings (generated by script)
├── images/
│   └── Arun.jpg                 # Known face image (add more here)
└── README.md                    # Project documentation


🧰 Requirements

Install dependencies using pip:
sudo apt update
sudo apt install python3-pip
pip install opencv-python face_recognition dlib numpy

⚠️ Note:
On Kali Linux, dlib requires cmake and build-essential:
sudo apt install cmake build-essential


🧠 How It Works

1. `encode_faces.py` → Loads known images from `images/`, creates encodings, and saves them into `encodings.pkl`.
2. `face_recognition_live.py` → Opens webcam, reads live frames, compares detected faces with stored encodings, and displays the name if matched.

▶️ How to Run

Step 1 — Encode Known Faces

python3 encode_faces.py


Step 2 — Start Live Recognition

python3 face_recognition_live.py

Step 3 — Test

Look into the camera — it should recognize your face and display your name (e.g., *Arun*).

🧪Example Output

When your face is detected, you’ll see a window like this:

```
[INFO] Recognized: Arun
```
